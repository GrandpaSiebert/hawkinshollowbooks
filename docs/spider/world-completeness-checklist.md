# World Completeness Checklist

## Priority Order

1. Phase A: Finish the World
2. Phase A.1: Verify Cross-Links
3. Phase B: Neighborhood Walk Verified
4. Phase C: Spider Verified
5. Phase D: Living World

## Phase Roadmap

### Phase A - World Complete

- Core characters exist with foundation answers.
- Core locations exist with foundation answers.
- Series pages use the shared invitation rhythm.

### Phase B - Neighborhood Walk Verified

Start anywhere. Within ten minutes, can a visitor naturally discover one story, one character, one place, and one new friend without wondering where to go next?

If yes, the neighborhood is alive.

### Phase C - Spider Verified

Spider walks consistently report welcome, orientation, and belonging across representative journeys.

### Phase D - Living World

Spider notes trend toward delight-first observations while friction remains occasional and actionable.

## Phase A Definition

Phase A is complete when each core character and core location can answer its foundation questions clearly.

### Character Foundation Questions

- Who am I?
- Why might we become friends?
- Where do I belong in Hawkins Hollow?
- Where might we go together next?

### Place Foundation Questions

- What is this place?
- Why is it important?
- Who comes here?
- What stories happen here?
- Where could I wander next?

## Phase A.1 Cross-Link Verification

Before Spider, verify enough cross-links to make the world feel connected.

Cross-link verification is complete when each core character and each core location has:

- At least one meaningful incoming link from another core page.
- At least one meaningful outgoing link to another core page.
- At least one character-to-place path and one place-to-character path.

Example neighborhood chain to verify:

- Spencer -> Reading Stump -> Alice -> Old Oak -> Community Garden -> Callen

## Gating Rule Before Spider

Do not run the first full Spider pass until:

- At least 90 percent of core characters are marked Complete.
- At least 90 percent of core locations are marked Complete.
- At least 90 percent of core characters and core locations are marked Cross-link Verified.
- Series pages all use the shared invitation and next-step rhythm.
- Neighborhood Walk Verified is passed.

## Spider Entry Condition

Begin Spider only when the world is populated enough that repeated "page feels empty" findings no longer dominate the observations.
