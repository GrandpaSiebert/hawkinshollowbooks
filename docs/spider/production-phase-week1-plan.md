# Hawkins Hollow Production Phase - Week 1 Plan

Adopted: 2026-08-02

## Objective

Transition from architecture work to production execution by completing core world population and validating walkability before the first Spider pass.

## Sequencing Rule

Finish each batch fully before starting the next batch.

## Batch 1 - Core Characters

Goal: Every primary character meets the Character Complete standard.

Required for each character:

- Identity is clear.
- Introduction feels welcoming.
- Series appearances are listed.
- Related stories are connected.
- Related places are connected.
- Related characters are connected.
- One gentle next step is present.

Definition of done for Batch 1:

- All primary characters marked Complete in docs/spider/core-characters-checklist.csv.
- Cross-link fields are filled for each primary character.

## Batch 2 - Core Locations

Goal: Every primary location meets the Location Complete standard.

Required for each location:

- Purpose is clear.
- Emotional role is clear.
- Stories in this location are connected.
- Characters in this location are connected.
- Nearby places are connected.
- One gentle next step is present.

Definition of done for Batch 2:

- All primary locations marked Complete in docs/spider/core-locations-checklist.csv.
- Cross-link fields are filled for each primary location.

## Batch 3 - Neighborhood Connections

Goal: Move from isolated completeness to connected walkability.

Checkpoints:

- Each core character has at least one incoming and one outgoing meaningful core link.
- Each core location has at least one incoming and one outgoing meaningful core link.
- Character to place and place to character paths are present.

Definition of done for Batch 3:

- Cross-link Verified is Yes for at least 90 percent of core characters.
- Cross-link Verified is Yes for at least 90 percent of core locations.

## Batch 4 - Neighborhood Walk Verified

Goal: Validate road continuity before Spider evaluation.

Test journey format:

- Character
- Story
- Location
- Character
- Story

Pass criteria:

- Walk can continue naturally for ten minutes.
- No dead ends.
- No repetition fatigue.
- No uncertainty about what to do next.

Definition of done for Batch 4:

- Neighborhood Walk - Verification status can be set to complete in docs/spider/world-completeness-checklist.md.

## Batch 5 - Spider (First Walk)

Goal: Evaluate lived experience, not missing content.

Evaluation focus:

- Welcome
- Orientation
- Pacing
- Belonging

Definition of done for Batch 5:

- Observation entries captured in docs/spider/hawkins-hollow-spider-observation.csv.
- Patterns distilled into docs/spider/spider-action-sheet.csv.

## Production Guardrails

- Reuse proven patterns before inventing new ones.
- Prefer metadata-driven links over manual per-page guesswork.
- Do not add new behavior unless the Spider would have asked for it.
- Keep implementation changes aligned to the Design Charter.

## Daily Closeout Checklist

- Update character and location completion checklists.
- Update world completeness status board.
- Record one Keep Signal discovered that day.
- Record one friction pattern discovered that day.
- Identify the smallest next batchable task for tomorrow.
