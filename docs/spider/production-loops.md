# Hawkins Hollow Production Loops

Adopted: 2026-08-02

## Principle

Every production day has three parts:

1. Produce
2. Verify
3. Learn

Learning is constrained.

Ask:

What did today's work teach us about tomorrow's work?

Do not ask:

How should we redesign Hawkins Hollow?

## Daily Loop

Batch

-> Verify

-> Reflect

-> Tomorrow's Batch

Rules:

- No architecture changes in daily production batches.
- Keep scope bounded to approved patterns and checklists.
- End every batch with one reflection note.

Required reflection lens:

- What should tomorrow's batch do better?
- What did this batch teach us about Hawkins Hollow?

These are both required. The first improves production quality. The second deepens world truth.

## Weekly Loop

Characters

-> Locations

-> Connections

-> Neighborhood Walk

Outcome:

- The world becomes more complete and connected.
- Work proceeds in layers rather than context switching.

## Long Loop

Spider

-> Patterns

-> Template Refinement

-> Better Future Batches

Outcome:

- The visitor experience steadily improves.
- Production gets easier and more consistent over time.

## Charter Boundary

There is no automatic loop from production back into the Design Charter.

Charter amendments happen only when repeated lived visitor experience reveals a true conflict with its principles.

## Batch Transparency Standard

Each batch must show:

- Clear scope
- Definition of done
- Verification performed
- Reflection recorded

## Progress Metrics

Primary:

N more neighbors moved into Hawkins Hollow today.

Continuous improvement:

N more neighbors moved into Hawkins Hollow today, and tomorrow they will be easier to welcome.

Interpretation guardrail:

- First half tracks growth.
- Second half tracks learning.

Growth without learning becomes inconsistent.

Learning without growth becomes planning.
