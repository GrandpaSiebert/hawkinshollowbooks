# ADR-007: One Production Pain Rule

## Decision

Infrastructure work is complete unless production experience proves otherwise.

No infrastructure feature is added unless it solves a real production problem that has actually occurred.

## Why

Hawkins Hollow now has stable infrastructure, publishing discipline, architecture records, and a learning framework. The highest return now comes from stories, companion packs, and family experience quality.

## Alternatives Considered

- Continue proactive infrastructure feature expansion based on anticipated needs.
- Add architecture and publishing enhancements whenever implementation ideas appear.

## Consequences

- Infrastructure changes become evidence-led, not idea-led.
- Backlog priority remains on content production and visitor experience.
- New infrastructure work requires a clear production incident, repeated operational friction, or a verified reliability gap.
