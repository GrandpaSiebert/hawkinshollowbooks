# ADR-001: Local Library Is Authoritative

## Decision

The local Library is the authoritative working environment for content creation and organization.

## Why

The local Library reflects accumulated creator workflow and domain knowledge. Reorganizing it to match cloud storage conventions would create friction and risk without improving creative output.

## Alternatives Considered

- Reorganize local Library to match R2 prefixes.
- Maintain dual manual structures (local and cloud) with hand-managed synchronization.

## Consequences

- Publishing software must adapt local structure to distribution targets.
- Mapping and manifest tooling become core infrastructure responsibilities.
- Workflow continuity is preserved for creators and collaborators.
